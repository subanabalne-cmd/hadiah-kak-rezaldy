# 🎁 Website Hadiah Kenangan MOB untuk Kak Rezaldo

Website apresiasi dan kenangan interaktif dari 19 mahasiswa bimbingan Masa Orientasi Bersama (MOB) untuk kakak pendamping (**Kak Rezaldo**).

---

## 🌟 Fitur Utama

1. **💌 Pembuka Interaktif Amplop (Envelope Screen)**:
   - Tampilan pembuka bergaya amplop pastel dengan animasi dan letupan confetti saat dibuka.
2. **⭐ Center of Attention (Spotlight Kak Rezaldo)**:
   - Posisi paling tengah dan paling menonjol dengan bingkai polaroid emas, washi tape, deskripsi apresiasi, serta tombol reaksi *Love* dan *Tepuk Tangan* interaktif.
3. **📸 Galeri Polaroid 19 Anggota Bimbingan**:
   - Grid polaroid dengan sentuhan pinboard/scrapbook (sedikit miring secara alami, washi tape warna-warni, kutipan tulisan tangan).
   - Dilengkapi filter kategori (Semua, Terharu & Apresiasi, Kocak & Santai) serta pencarian langsung.
4. **📖 Modal Baca Surat Lengkap**:
   - Klik kartu untuk membaca surat pesan yang lebih panjang dari masing-masing teman bimbingan, dilengkapi tombol love per pesan.
5. **🎬 Mode Story / Slideshow**:
   - Bisa diputar otomatis seperti Instagram Story, mulai dari Kak Rezaldo lalu berurutan ke 19 anggota kelompok.
6. **🎵 Pemutar Musik Suasana (Web Audio API)**:
   - Melodi lofi akustik yang menenangkan, dibuat langsung menggunakan synthesizer browser tanpa perlu file MP3 eksternal (100% bebas error/404).
7. **✏️ Fitur Edit & Upload Foto Langsung di Browser**:
   - Klik tombol **"Edit Foto & Pesan"** di pojok kanan atas untuk mengganti nama, pesan, atau memilih foto asli dari galeri HP/laptop.
   - Perubahan otomatis tersimpan di memori browser (localStorage).
8. **📥 Tombol "Unduh File Jadi"**:
   - Menghasilkan 1 file HTML utuh yang sudah mencakup foto dan teks yang telah kamu ubah, sehingga siap dikirim atau dibuka di perangkat mana pun.

---

## 🚀 Cara Membagikan Website Ini ke Kak Rezaldo

### Cara 1: Online Gratis via Netlify Drop (Paling Praktis)
1. Buka [app.netlify.com/drop](https://app.netlify.com/drop) di browser.
2. Seret (*drag & drop*) folder `website-rezaldy` ini.
3. Dalam hitungan detik, kamu akan mendapatkan link website aktif (misal: `https://kenangan-kak-rezaldy.netlify.app`).
4. Kirim link tersebut ke Kak Rezaldo lewat WhatsApp!

### Cara 2: Kirim File Langsung
1. Buka file `index.html` di browser kamu.
2. Sesuaikan foto atau pesan jika ada yang ingin diubah.
3. Klik tombol **"Unduh File Jadi"**.
4. Kirim file `.html` hasil unduhan melalui WhatsApp Dokumen atau Google Drive. Kak Rezaldo bisa langsung membukanya di HP atau laptop.

### Cara 3: Hosting via GitHub Pages atau Vercel
- Upload folder ini ke repository GitHub, lalu aktifkan **GitHub Pages** di menu *Settings* repository.
