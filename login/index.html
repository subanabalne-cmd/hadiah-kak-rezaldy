Cara Membagikan Website Ini ke Kak Rezaldo

Pilih salah satu cara termudah berikut ini agar Kak Rezaldo bisa membukanya!

1. Online Gratis & Cepat via Netlify Drop (Sangat Direkomendasikan ⭐)

Buka link app.netlify.com/drop di browser.
Cukup seret (drag-and-drop) folder website ini atau file index.html. Dalam 10 detik kamu akan langsung dapat link online aktif (contoh: https://hadiah-kak-rezaldo.netlify.app) yang bisa langsung di-copy dan dikirim ke Kak Rezaldo lewat WhatsApp!

2. Bagikan File Langsung (Tanpa Perlu Hosting)

Klik tombol "Unduh File Jadi" di pojok kanan atas. File index.html yang terunduh sudah memuat semua foto dan tulisan pesanmu secara utuh. File tersebut bisa langsung kamu kirim lewat WA dokumen / Google Drive, dan Kak Rezaldo bisa membukanya langsung di Chrome/Safari HP maupun laptop.

3. GitHub Pages / Vercel (Untuk Kamu yang Punya Akun Dev)

Push folder ini ke repository GitHub baru, lalu aktifkan fitur GitHub Pages di tab Settings → Pages. Website akan langsung aktif di link domain gratis GitHub!
